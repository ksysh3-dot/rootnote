## 일하는 방식 (사용자 합의)
- 모든 사용자 출력은 한국어다.
- 역할: Opus가 설계·지시·판정하고, 작업은 Sonnet (medium)이 한다. max는 정말 필요할 때만 쓴다.
- 병합·출시·앱 반영 시점은 사용자 결정이다.
- **판정 절차 (16.16)**
  - 기준선은 P1이다. 지킴은 들리는 해악 4개 (어택, 공백·깜빡임, 잡음 터짐, 음 소실) + 몸통이다.
  - 실패는 "P1보다 나쁘고 동시에 비교 판보다 폭을 넘게 나쁠 때"만 센다.
  - 개선과 악화가 섞이면 개선폭 대 악화폭으로 판정한다.
  - 0단계 멈춤은 오라클도 이득이 없을 때만이다.
  - 문턱은 결과를 본 뒤 바꾸지 않는다. 결함이면 기록하고 정정한다.
- 사전 등록마다 짧은 검토를 받는다 (GPT 보조 감수, 또는 사용자 승인 시 Sonnet). 질문은 셋이다: 지표가 불만을 재는가, 기준선이 P1인가, 뺄 것은.
- **대역 지표는 누설 몫부터 잰다** (19.5: 옛 주 지표의 20–150 Hz는 97 %가 누설이었다). 쿠쿠쿵 주 지표는 Hann FFT 20–140 / 150–600과 150 Hz 아래 절대 수준이다. 들리는 쪽 보조는 150–260 Hz 포락선 변조다.
- 청감은 거부권이 아니다. 블라인드만 판정에 쓴다 (LiveAb는 s26u판에만 있다). 해석은 듣기 전에 고정한다.
- 음악·데이터셋·오디오는 커밋하지 않는다. 사용자 음악은 그 자리에서 읽기만 한다.
  - vanila 14곡: `C:\Users\ksysh\Music\vanila`
  - Rayark 23곡: `C:\Users\ksysh\Music\Rayark ...`
  - 폰 음악 백업: `C:\Users\ksysh\Desktop\백업\SdCardBackUp\Music`
  - Last Carnival: 다운로드 폴더
- Slakh validation/test는 열지 않는다 (ls도 금지). 다운로드는 허락을 받는다.
- 커밋 이름은 ksysh3-dot이고, 메시지는 파일로 넘긴다. push는 Windows 저장소 (`rootnote-duo\repo`)에서 한다. WSL `~/rootnote`에서 fetch한 뒤 `push origin FETCH_HEAD:refs/heads/<branch>`로 올린다.
