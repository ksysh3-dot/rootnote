# Rootnote 디자인 가이드

Rootnote(일반 배포판)의 화면을 만들거나 고칠 때 따르는 기준이다. 코드의 토큰 이름(`rn_*`, `HomeScreen.kt`)과 Figma 파일 "Rootnote 아이콘"(페이지 "개발자 모드 시안" 포함)이 이 문서와 같은 값을 쓴다. 값이 어긋나면 이 문서를 고치고 코드와 Figma를 맞춘다.

## 1. 방향

- **구조는 당근 SEED식:** 카드를 쌓지 않고, 섹션 제목 + 행 목록 + 섹션 사이 회색 띠로 나눈다.
- **움직임은 둘로 나눈다:** 시스템이 상태를 바꿀 때는 당근 SEED의 시간·곡선, 손가락이 잡고 있는 값은 Apple식 스프링. 정지된 화면 전환은 없다.
- **삼성 One UI 가이드는 참고만 한다.** 따르지 않는 것:
  - 화면마다 제각각인 모서리 곡률 → 반경은 아래 두 종류로만 통일한다.
  - 움직임이 없거나 딱딱한 전환 → 6절의 시간·곡선을 쓴다.
- Material 3는 시스템 구성 요소(대화상자, 시트, 텍스트 필드)의 바탕으로만 쓰고, 겉모습은 이 가이드로 덮는다. Material 3 Expressive의 과장된 모양과 크기 변화는 쓰지 않는다.

### 2.3 그라데이션 (여유·위험 정도를 나타낼 때만)

초록 #2E9E5B (0) → 노랑 #E8C547 (0.45) → 주황 #E8892F (0.72) → 빨강 #D64545 (1.0).
- 바탕 트랙은 30% 불투명, 채움은 100%이고 채움의 끝 색은 그 위치의 트랙 색과 같아야 한다(늘려 맞추지 않는다).
- 광택, 흐림, 그림자는 쓰지 않는다.

### 2.4 색 규칙

- 글자 대비 4.5:1 이상(밝은·어두운 모드 모두). 노랑·주황 위 글자는 어두운 글자.
- 색만으로 뜻을 전하지 않는다. 항상 글자(상태 이름)나 위치 표시가 함께 있다.
- 틸 외의 강조색을 새로 들이지 않는다. 경고는 주황, 위험은 빨강뿐이다.

## 3. 글자

- 앱은 시스템 기본 글꼴을 쓴다(갤럭시에서는 One UI 글꼴). 시안은 Noto Sans KR로 대신 그린다.
- 크기 단계 (sp / 줄 높이):

| 단계 | 크기 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| 큰 숫자 | 44~56 / 1.1배 | Bold | 게이지 숫자 |
| 머리말 | 22 / 30, 자간 −0.4 | Bold | 메인 화면 상태 문장 |
| 화면 제목 | 20 / 26, 자간 −0.3 | Bold | 상단 바 |
| 행 제목 | 16 / 22 | Bold | 행, 슬라이더 이름, 값 |
| 본문 | 15 / 21 | Regular | 대화상자 본문, 버튼(굵게) |
| 보조 | 13~14 / 18~20 | Regular | 행 설명, 칩(14) |
| 작은 글자 | 11~12 / 16 | Medium | 그래프 축, 근거 표시(10~11) |

- 문체: "~해요"체, 한 문장은 짧게. 수치 설명은 "올리면 ~해요 / 너무 올리면 ~할 수 있어요" 형식(문구 원본: `docs/DEVMODE_COPY.md`).

## 4. 간격과 형태

- 좌우 여백 16 dp. 섹션 사이는 8 dp 높이의 rn_band 띠.
- 행 최소 높이: 이동 행 56, 설명 있는 스위치 행 72, 머리 행 96. 행 안 세로 여백 12~14.
- 모서리 반경은 두 종류만:
  - **알약**: 높이의 절반 (칩 36→18, 버튼 48→24, 스위치, 게이지 트랙)
  - **둥근 사각**: 14 (행 묶음 카드, 슬라이더 카드, 근거 행) / 20 (그림 카드) / 24~28 (대화상자, 시트 위쪽)
- 터치 영역 48 dp 이상(보이는 크기가 작아도 영역은 48).

## 6. 움직임

기준은 하나다. **손가락이 값을 잡고 있으면 Apple, 시스템이 상태를 바꾸면 SEED.** 잡고 있는 동안은 손가락과 1:1(스냅)이고, 놓은 뒤에만 스프링이 현재 값과 속도를 이어받는다. 모든 값은 `ui/RnMotion.kt` 한 곳에만 정의하고, 화면 파일은 `tween(`·`spring(`·`CubicBezierEasing(`을 직접 부르지 않는다(`tools/check_motion.py`가 CI에서 검사).

### 6.1 SEED 토큰 (시스템이 바꾸는 상태)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `D3` | 150 ms | 색·투명도, 글자 교체, 눌림 시작, 하단 버튼 교체 |
| `D4` | 200 ms | 홈 탭 교체(높이 변화 포함), 닫힘(대화상자·화면 나가기) |
| `D6` | 300 ms | 크기·위치 이동, 대화상자·페이지 들어오기. 탭 한 번에 300 ms를 넘는 움직임은 없다 |
| `Easing` | (0.35, 0, 0.35, 1) | 기능적인 작은 움직임 전부 |
| `Enter` | (0, 0, 0.15, 1) | 들어오기, 눌림 시작 곡선 |
| `Exit` | (0.35, 0, 1, 1) | 나가기 |

### 6.2 Apple 스프링 (손가락이 잡았다 놓은 값)

| 이름 | 감쇠 / 강성 | 쓰는 곳 |
|---|---|---|
| `settle` | 1.0 / 247 | 슬라이더·균형 점에서 손을 뗀 뒤 위치 |
| `thumb` | 1.0 / 439 | 눌림에서 뗄 때 크기 복귀, 스위치 손잡이와 바탕색(진행값 하나가 둘을 같이 움직임), 슬라이더 손잡이 크기 |
| `needle` | 0.7 / 200 | 레벨미터 바늘처럼 실시간 값을 따라가는 것. 표본마다 새로 시작하지 않는다 |
| `fling` | 0.8 / 439 | 시트·페이저에 예약(지금 직접 쓰는 곳 없음) |

### 6.3 규칙

- 눌림: 누르는 즉시 배경색이 바뀌고(스냅) 뗄 때 D3로 돌아온다. 크기는 누를 때 `Seed.pressIn`(D3), 뗄 때 `Apple.thumb`. 축소 0.94~0.96.
- 슬라이더: 끄는 동안 손잡이는 손가락 위치 그대로. 놓으면 `settle`. 누르고 있는 손잡이는 1.15배(`pressIn`/`thumb`).
- 스위치·슬라이더·눌림은 `ui/RnControls.kt`, `ui/RnSlider.kt`에 하나씩만 있다. 홈·개발자 모드·균형 화면이 따로 만들지 않는다.
- 글자·탭 교체는 `RnSwap`(교차 페이드, 크기도 같은 시간·곡선).
- 대화상자(`RnDialogHost`): 창 기본 애니메이션과 어둡게 하기를 끄고, 어두운 막은 D6 `Enter`로 0→0.32, 카드는 0.96→1 + 투명도. 닫을 때는 D4 `Exit`가 **끝난 뒤** 맡긴 동작이 실행된다. 들어오는 동안에도 입력은 막지 않는다. 뒤로 가기·막 탭은 닫기 동작과 같다(진행 대화상자는 둘 다 막음).
- 시트(`ModalBottomSheet`, Material 3 1.3.2): 그대로 쓴다. 모양은 5절, 움직임과 예측 뒤로 가기는 라이브러리 기본을 따른다. 이 판단은 소스를 읽어 한 것이며 기기에서 잰 값이 아니다.
- 화면 이동은 시스템 액티비티 전환을 그대로 쓴다. 예측 뒤로 가기(`enableOnBackInvokedCallback`)는 Compose 액티비티 12개에 켜져 있다. 첫 실행 안내처럼 한 액티비티 안의 페이지는 들어올 때 `Seed.enter`, 나갈 때 `Seed.exit`.
- 첫 실행 안내의 아래 버튼은 바로 눌린다. 다만 "확인하고 시작하기"만 나타난 뒤 0.4초 동안 탭을 무시한다(이중 탭으로 동의가 넘어가는 것을 막기 위함).
- 매 프레임 바뀌는 값(투명도·이동·색)은 그리기 단계에서 읽는다(`graphicsLayer { }`, `drawBehind { }`). 컴포지션에서 읽지 않는다.
- 이야기 그림은 한 번 재생하고 대표 장면에서 멈춘다. 그림을 누르면 다시 재생한다(`story_replay`). 끝없이 도는 움직임은 두지 않는다. 예외: 베이스 이야기 6번 장면의 시험 중 맥박(시험이 도는 동안만).
- 일부러 따르지 않은 것: Apple의 바운스 스프링(감쇠 < 1)은 바늘 외에 쓰지 않는다. 당근 SEED의 시간 토큰 중 D1·D2·D5는 쓸 곳이 없어 만들지 않았다.

## 7. 아이콘

- 앱 아이콘: 빔으로 이은 아르페지오(♫). 첫 음표 머리는 비어 있다(들리지 않는 기음), 나머지는 배음. 적응형 아이콘 108 dp, 안전 영역 66 dp, 배경 rn_fill(#0B7A7A).
- 알림·빠른 설정·작은 아이콘: 같은 모양을 잘라 쓰고 기둥을 두 배로 굵게 한다(24 dp에서 보이도록).
- 화면 안 기호 아이콘: 2 dp 선, 둥근 끝. 그림 문자(이모지)는 쓰지 않는다.

## 8. 접근성

- 모든 그림에 TalkBack용 요약 문장(예: "기음 55 Hz, 배음 4개, 가장 큰 배음 165 Hz, 여유 3 dB").
- 모든 슬라이더는 ± 버튼으로도 조절할 수 있다.
- 머리말과 섹션 제목은 heading으로 표시한다.
- 상태 변화(켜짐·꺼짐, 경고)는 글자로도 바뀐다.
- 글자 크기 확대(200%)에서 잘리지 않게 높이는 내용에 맞춰 늘어난다(고정 높이 금지).
- **움직임 줄이기:** 시스템의 애니메이션 배율이 0이면(가) 모든 움직임이 즉시 바뀐다(스냅). 읽는 곳은 `ProvideRnMotion` 하나뿐이고, 화면은 `rn(spec)`을 거친다. 설정을 바꾸면 화면을 닫지 않아도 바로 반영된다.

## 9. 하지 말 것

- 광택, 유리 반사, 무거운 그림자, 그라데이션 배경 칠.
- 왼쪽 굵은 테두리로 강조하는 카드, 이모지 아이콘.
- 새 모서리 반경, 새 강조색, 화면마다 다른 곡선.
- 근거 없이 단정하는 설명. 확인 안 된 것은 "추정"으로 표시한다.
