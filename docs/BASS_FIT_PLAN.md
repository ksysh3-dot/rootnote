# "저음 맞추기" (bass fit): in-app listening tests

Status: plan, 2026-10-24. Engine knob (step 0) and the pure test logic (`pvb/BassFit.kt`, `jvm/BassFitTest.kt`) done; screen not started. First shipped in developer mode only; opened
to everyone after the S26 Ultra result matches the UMIK-1 measurement.

## Goal

Let the user find, by ear and blind, the settings their own phone needs: where the speaker stops (floor), how much
virtual bass, where harmonics break up, and (optionally) the harmonic shape. No third-party data needed.

## Common rules

- **Volume fixed** at the user's usual listening volume, recorded with the result; a volume change pauses the test.
  The volume link scales the result for other volumes.
- **Signals generated by the app** (no copyrighted audio). The final check uses the user's own playing music.
- **Blind:** A/B/X order random every trial; catch trials (silence, identical pair) mixed in.
- **ABX decision:** up to 8 trials; "distinguishable" at 7/8 or better (one-sided binomial p < 0.05); stop early at 6/6.
- **Consistency:** repeated pairs; under 70 % agreement, the step's result is not applied (defaults kept).
- **"No difference" keeps the lower / default value.** Safety caps always apply: low-mid boost <= +3 dB, virtual bass
  <= break-up limit - 3 dB, test signals below the S26 Ultra's measured protection threshold.
- Results are saved as "my fit", separate from the defaults, reversible, and included in the settings share code.

## Noise gate (strict)

Before step 1, with the phone microphone (the permission the measurement features already use):

1. Record 3 s of the room with nothing playing.
2. Play the test reference (the test band at test level) for 2 s and record it.
3. Per third-octave band of the test (63-500 Hz) and of the speech band (500-4000 Hz): signal-to-noise ratio, and
   how much the room level jumps (100 ms frames: max - median).
4. **Pass only if** SNR >= 35 dB in every test band and the room level jumps by <= 6 dB. The ratio is relative, so an
   uncalibrated phone microphone is enough.
5. Otherwise: "주변이 시끄러워서 결과가 부정확할 수 있어요! 그래도 진행할까요?" [조용한 곳에서 다시] [그래도 진행].
   Proceeding marks the result "noisy" (lower confidence; never used as shared data).
6. No microphone permission: "주변이 조용한지 확인할 수 없어요" with the same choice.
7. During the test the silent interval of each two-interval trial is monitored; a noise burst above the gate discards
   that trial and repeats it.

## Steps

| Step | What it finds | Method | Time |
|---|---|---|---|
| 1 | Speaker floor (lowest note the speaker itself plays cleanly) | Two-interval forced choice ("어느 쪽에서 소리가 났나요?"), tone bursts from 300 Hz down in 1/6-octave steps, 2-down/1-up staircase (Levitt 1971; QUEST/Psi possible later), option "윙·지직만 났어요" counts as not heard; optional phone-mic bass check alongside. Then ABX: edge at floor vs floor x 1.3 on a 150-250 Hz bass line; no difference keeps the lower | 3 min |
| 2 | Is the layer audible; preferred strength | ABX off vs +4; then blind A/B "better / no difference" climbing over 0..+8 dB in 2 dB steps from the middle (2 vs 4, then 0 vs 2 or 4 vs 6, then 6 vs 8); ties take the lower; the first pair is asked again for consistency | 2 min |
| 3 | Break-up limit | Layer raised in 3 dB steps; ABX current vs 6 dB lower, "어느 쪽이 지직거리나요?"; first distinguishable step = break-up; limit = break-up - 3 dB, also the volume link's start | 2 min |
| 4 (optional, precision) | Harmonic shape | Two knobs only: tilt (existing roll-off value) and low-order weight (H2 vs H3-5, existing harmonic offsets). 3 x 3 grid, ~18-20 blind pairs chosen where the ranking is uncertain, Bradley-Terry scores; Gaussian-process preference learning later if needed | 5-7 min |
| Check | New vs previous settings on real music | Live blind A/B (existing) | 1 min |

## What each result sets

| Result | Settings |
|---|---|
| Speaker floor F | `speaker_floor_hz` = F; high-pass = max(80, 0.6 F); generator edge = 190 x F/150; output band low edge = 150 x F/150; table scale = F/150 (engine `P_D_TABLE_SCALE`) |
| Preferred strength | virtual bass strength (capped by step 3) |
| Break-up limit | strength cap; volume-link start |
| Harmonic shape | roll-off offset, harmonic offsets k = 2..5 |

## Engine (step 0, done)

`P_D_TABLE_SCALE` (index 56; 1 or 0 = model, 0.75..1.75): the virtual-bass weight/gain table is looked up at
f / scale, and the table's upper frequency clamp moves with it. The generator edge may now go up to 280 Hz. Default
and zero are bit-identical to the model (test_devmode "in tree"); a moved value changes the output.

First host measurement (layer level re the source band, dB; model = S26 Ultra):

| Note | 55 | 98 | 131 | 147 | 165 | 185 | 200 | 220 | 240 Hz |
|---|---|---|---|---|---|---|---|---|---|
| Model | -17 | -9 | -13 | -23 | -33 | -34 | none | none | none |
| Floor 200 (scale 1.33, edge 253, out low 200) | -24 | -23 | -16 | -18 | -21 | -27 | -35 | -44 | -45 |

The scale fills 147-240 Hz as intended but also lowers 55-98 Hz notes, because the table's level matching is tied to
the S26 Ultra's speaker. Before the scale becomes a default, check it with a frequency-shifted speaker model
(`study/phone_model.py`): the perceived bass on a "floor 200" speaker with the scale should match the S26 Ultra's with
the model.

## Test logic check (simulated listeners, BassFitTest)

- Guessing listener judged "distinguished" in 3.6 % of ABX runs; a 95 %-right listener in 94 %.
- Floor staircase: median error 0.08-0.09 octave, 90th percentile 0.25-0.29 octave (true floors 130-240 Hz,
  logistic listener); a listener who "hears" silent catch trials is marked unreliable.
- Strength: lands on the level nearest the listener's ideal; ties keep the lower; a reversed repeat is flagged.
- Break-up: found at the right step in 94 % of runs (the rest are guessing false alarms on lower steps).
- Shape grid: the preferred cell found in 37-40 of 40 runs with 18 pairs (noisy listener).
