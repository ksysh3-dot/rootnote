## Resultant R1: 배음 위상 정렬 (시제품)

**상태:** 개발 단계 시제품 (합성 개발 픽스처만, 확인군·청감 없음). 호스트 연구 stage flag `1048576` (`StagePhaseCrest`), 앱·기본값 변경 없음.
**브랜치:** `research/resultant-r1-20261029` (`research/resultant-r0-20261029` 위).
**출발점:** 0단계 (`docs/RESULTANT_PHASE0.md`) — 단음의 유효 배음은 이미 ≈ 100 %라, 같은 피크에서 남은 여지는 배음 위상뿐 (중앙값 +1.3 dB).

### 무엇을 바꾸나
- P1은 입력에 자기 배음이 없는 배음 (unreferenced)에 고정 오프셋 `kPsi = π k² / 6` (같은 크기 배음 6개용 Schroeder형)을 준다. 실제 배음 크기 (표 가중치 × 출력 필터)와 출력 필터 위상은 이 가정과 달라 파고율이 최적보다 높다.
- `research_r1_phase_table.py`: 32–190 Hz를 0.5 Hz 간격으로 P1 (flags 0) 순음을 렌더하고, 생성층의 배음 2–8을 맞춘 뒤, 그 크기에서 파고율이 가장 낮은 위상을 찾아 `kPsi`에서의 변화량 Δk(f)를 표로 만든다 (`pvb_vb_r1_tables.h`, 317 × 7). 파고율이 같은 시간 이동 (k α)·시간 반전 중 이전 격자점에 가장 가까운 것을 골라 f 방향으로 이어지게 했다 (최적해 전환 5곳, 가중 최대 계단 1.05 rad).
- 엔진: 플래그가 있으면 unreferenced 배음의 목표 오프셋이 `kPsi + Δk(f)` (f 선형 보간). 트랙은 여전히 `kPsi`로 태어나고, 기존 위상 슬루 (홉당 ±0.12 rad)로 약 0.1 s에 걸쳐 옮겨 간다. 입력 배음을 따르는 배음과 타격 경로 (`bandLayer`)는 그대로.
- 플래그 0 및 기존 플래그 (6, 8192, 163840, 4, 1)는 비트 동일 (6개 픽스처 × 6개 설정, 출력·스템 SHA-256). 로컬 엔진 시험 6종 통과.

### 결과 (`research_r1_candidate.py`, P1 / P1 + R1)
같은 피크 이득 = 생성층 RMS 변화 − 생성층 true peak 변화 (파일 전체, 48 kHz).

|---|---|---|

| 단음 55 Hz 이하 4개 | +1.76 – +2.28 | +1.94 – +2.80 |
| AM 3개 | +1.17 – +2.15 | +2.12 – +2.70 |
| 비브라토 55 Hz | +1.67 | +2.09 |
| 떨어진 두 음 4개 | +0.39 – +2.29 (중앙값 +1.13) | +0.83 – +1.74 |
| 짧은 음 8개 | 중앙값 +0.37, −0.24 – +2.01 | — |
| 808형 (49 Hz, 하강 글라이드·감쇠) | −0.15 | — |

- 부작용: 배음 크기 변화 ≤ 0.09 dB, 음높이 ≤ 0.004 cent, 피치 명료도 대리 지표 (감마톤 40채널 요약 자기상관, T0 정규화 값) 변화 −0.006 – +0.003 (중앙값 0), 경쟁 주기 대비 우세도 변화 ≥ −0.025.
- P1 + C1 (Legato 1.1)도 같은 경향: 단음 파일 전체 중앙값 +0.86, 짧은 음 +0.02 – +1.88, 808 −0.15.
- 정확한 3:2 쌍 (55 / 82.5 Hz)은 두 음이 공유하는 165 Hz 배음의 합이 커져 RMS +2.1 dB (피크 +0.8 dB) — 배음 크기 자체의 변화로 남긴다. 평균율 쌍은 RMS 변화 ≈ 0.

### 개발 중 기각한 변형 (같은 지표)
| 변형 | 단음 | 짧은 음 중앙값 / 최소 | 808 | 배음 풍부 뜯는 음 중앙값 / 최소 |
|---|---|---|---|---|
| T: 태어날 때부터 표 + 타격 경로도 표 | +1.35 | +1.28 / +0.40 | +0.55 | −0.24 / −3.73 |
| K: 태어날 때부터 표, 타격 경로 `kPsi` | +1.35 | +0.37 / −0.50 | −0.77 | +0.01 / −0.98 |
| T + 순간 주파수 순도로 섞기 | +1.13 | +1.24 / +0.40 | +0.65 | −0.04 / −4.54 |
| **S (채택): `kPsi`로 태어나 슬루, 타격 경로 `kPsi`** | +1.00 | +0.37 / −0.24 | −0.15 | 0.00 / −0.02 |

- 음 시작에서는 타격 경로가 피크를 쥔다 (뜯는 음에서 지속 경로의 2–3배). 순음에서는 두 경로가 같은 위상 모양일 때 피크가 낮지만 (T), 배음이 풍부한 입력에서는 타격 경로의 파형이 표의 가정 (한 성분)과 달라 표 위상이 ±50 %의 피크 변화를 만든다. 순간 주파수 흔들림으로 둘을 가르는 시도는 순도가 시간에 따라 흔들려 위상 자체를 변조했다.
- S는 시작 구간을 P1 그대로 두는 대신 감쇠음 시작의 이득을 포기한다. 지속되는 부분에서만 이득이 난다.

### 한계
- 합성 입력만. 실곡에서는 입력에 자기 배음이 있는 배음 (referenced)이 많을수록 R1이 손대는 몫이 줄고, 감쇠음은 시작 피크가 남는다. 실곡 이득은 위 단음 값보다 작을 것이다.
- 지표는 생성층 단독. 드라이 신호를 합친 전체 출력의 피크는 재지 않았다.
- 피치 명료도는 계산 모델 대리값이다. 낮은 음의 미분해 배음에서 위상 변화가 들리는지는 청감으로만 판정된다.
- 표는 순음 기준이고 f 방향 계단이 있는 곳 (예: 37, 51.5, 75 Hz 부근)에서는 글라이드 중 위상이 슬루 한도로 따라간다.
