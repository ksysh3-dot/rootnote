# 개발자 시간 그래프: 단계별 배음 계측

2026-11-03. S77 수정 183.25 ms 엔진 위에 표시용 계측을 추가한다.

## 선의 정의

- 회색: 안정 분리기 이전의 공통 입력 저역. 안정은 `StableSeparator`가 내놓는 지연 정렬 원본을 사용한다.
- 연초록: 실제 합성기에 넣는 저역. 안정은 추정 베이스, 일반 P1 계열은 해당 합성기 입력이다.
- 틸 점선(선택): 합성·이득·공간 라우팅 후, 배음층 전용 피크 제어 전의 요청 배음.
- 틸 실선: 배음층 전용 피크 제어 후, 최종 합산·공유 리미터 전의 실제 배음 성분.

입력 두 선은 같은 개발자 저역 LPF와 모노 계산을 사용한다. 배음 두 선은 같은 전대역 스테레오 파워 계산을 사용한다. 모두 5 ms bin의 사인 등가 dBFS이며 표시축은 -100..0 dBFS다. 입력과 출력 배음은 서로 다른 대역의 신호이므로 그 차이를 분리 손실이나 이득으로 직접 해석하지 않는다.

배음층 제한량은 같은 bin의 요청/실제 에너지비다. 최종 리미터 감쇄는 별도 bin 최대값이다. 실제 배음 선은 최종 리미터·공유 게이트 뒤의 최종 청취 기여량이 아니다. 기존 배음 막대와 헤드룸 게이지의 계측 정의는 변경하지 않는다.

## 시간과 추적 상태

입력은 합성기 정렬과 공통 리미터 지연만큼 지연해 배음 성분과 대응시킨다. 48 kHz 강함·안정 경로가 이번 구성요소 대조의 검증 범위다. 실제 폰의 캡처·재생·OS 지연은 포함하지 않는다.

안정의 49,152샘플 내부 무음 준비 실행은 그래프와 사건 시계에서 제외한다. 실제 분리기 대기 3,192샘플은 오디오 시계에 포함하고 초기 빈 bin은 무음/관측 대기로 둔다.

추적 f0와 사유는 화면용 150 ms 유지값 대신 실제 HarmonicTrace를 읽는다. trace의 host grain centre와 공통 리미터 지연에 맞춰 관측을 예약하며 가장 강한 관측 트랙을 표시한다. 이는 합성 프레임 중심 관측이며 매 샘플의 정답 f0가 아니다. 5 ms 안의 모든 음·사유를 완전히 열거하는 추적기가 아니다.

- Birth/Tracked/Held를 새 트랙/관측 유지/유지 추정으로 구별한다.
- 실제 no-track 관측과 트랙 재관측에만 ×/○를 붙인다. 틸 레벨을 이용해 추적 소실을 추측하지 않는다.
- Fit 사유 비트는 맞춤 제한 관측으로 표시한다. 전체 배음 합성이 완전히 보류됐다고 단정하지 않는다.
- stationary raw fit 잔차를 dB로 표시하며 신뢰도 확률로 부르지 않는다.
- 엔진에 없는 재탐색 상태와 합성 불필요 판정을 새로 만들지 않는다.

## 정지와 꼬리

화면 정지 버튼·탭·길게 누르기는 스냅샷만 보존하며 음악은 계속 재생한다. 정지 후 드래그로 커서를 이동하고 실시간 버튼으로 복귀한다. 고정된 데이터 복사본을 사용한다.

꼬리 규칙의 상대 문턱은 이번 작업에서 튜닝하지 않는다. 그 규칙이 실제 사용한 합성기 입력 종료와 배음 종료를 괄호 및 선택 상세에 표시한다. 진행 중 꼬리를 확정 종료로 표시하지 않는다. 꼬리 경고는 청감상의 결함을 자동 확정하는 판정이 아니다.

## 검증

계측 ON 대 S77 계측 OFF의 15개 지원 조건에서 오디오 비트 동일성, 새 계측의 유한값, JNI 검사, 실제 진단 배음 PCM에서 계산한 RMS와 틸 계측의 일치를 확인한다. 계측 ON의 전환·리셋 스트레스는 ASan/UBSan 및 콜백 할당 검사로 확인한다. 실제 폰에서의 화면·터치·부하 검증은 남는다. 개발자 화면은 general flavor에 있으며 s26u 전용 flavor에 새 화면을 추가하지 않는다.
