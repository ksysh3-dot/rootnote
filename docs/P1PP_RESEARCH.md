# P1++: 기존 P1+의 오차를 줄이는 연구

2026-10-26 사용자 결정: [P1+](P1PLUS_BASELINE.md)를 임시 연구 기준으로 고정하고
기존 모델을 계속 정교화한다. 새 엔진으로 교체하는 것이 전제는 아니다.
이 문서는 다음 실험의 계약이며 P1++ 구현 완료나 성능 향상을 주장하지 않는다.

## 비교 기준과 진행 방식

1. P1, phase-only, P1+를 보존한다. 주 비교 대상은 P1+(`p1plus-2026-10-26`, flags 6)다.
   P1 대비 이득을 다시 계산해 이미 얻었던 위상 수정 효과를 새 성과로 세지 않는다.
2. 한 번에 한 원인을 바꾼다. 신호를 단순히 작게 하거나 정상 변조·어택을 지운 효과와
   불필요한 성분의 감소를 분리한다. 배음 세기와 지연은 허용하고 기록한다.
3. 개발 조건에서 원인을 찾고 변경과 평가법을 고정한 뒤 새 조건을 평가한다.
   이미 본 6조건과 12혼합은 회귀 자료다. 재실행을 독립 검증 표본으로 세지 않는다.
4. 알려진 입력의 목표 오차, 정상 음악적 변화의 보존, 실곡의 부작용을 따로 기록한다.
   평균 하나로 나쁜 조건을 숨기지 않고 조건별 결과와 최악 조건을 함께 본다.
5. 청감 AB는 중요한 추가 근거지만 수치 연구의 선행 승인 조건은 아니다.
   사용자 한 명이 반복 청취해야만 다음 구현을 진행하는 구조로 만들지 않는다.
6. 채택은 목표 조건의 개선과 다른 조건의 손실을 함께 판단한다. 모든 중간 지표의 동시
   개선을 요구하거나, 실곡의 출력 차이를 잡음 제거율로 해석하지 않는다.

## 첫 조사 대상: 큰 윤곽 오차의 원인 분리

현재 가장 큰 알려진 최종 오차는 약 45.46 Hz, 짧은 음+변조+별도 잡음 조건에서 남았다.
주 배음은 4차이며, 상대 윤곽 오차 RMS는 P1+에서도 82.8%다.
이를 저주파 자체의 실패로 단정하지 않고 아래 조건을 같은 시간축으로 비교한다.

- 저음만 입력 → 저음+정상 변조 → 저음+타격 잡음 → 모두 포함한 입력
- 잡음만 입력하여 잘못 생성되는 배음의 양과 지속 시간 확인
- 같은 음 길이에서 주파수만 변화, 같은 주파수에서 음 길이만 변화
- 입력 필터 → HPSS → 피크 관측/트랙 → 진폭 목표 → 합성 → 출력 필터의 단계별 기록

가설 A: 분리 단계의 누출/음 소실. 가설 B: 짧은 음의 관측·트랙 연결·진폭 갱신 지연.
가설 C: 출력 필터나 선택한 평가 채널의 영향. 각각을 시험해 수정할 위치를 정한다.
원인이 확인되기 전 새 게이트·추가 억제기·고차 모델을 기본값으로 쌓지 않는다.

## 이어서 다룰 대상

- P1+에서 악화한 7개 혼합 조건: 지속음 보존과 타격음 누출을 각각 평가한다.
- 생성 시작/종료, 트랙 교체와 초기화: 클릭·짧은 불필요한 성분·잔류음을 조사한다.
- 이미 좋아진 정상 변조와 위상 참조 조건을 회귀 검사로 고정한다.

## 기록과 자원 범위

실험마다 소스 버전, 입력 생성 규칙/난수, 라이브러리 해시, 보고 지연, 배음 세기,
조건별 오차와 처리 시간을 기록한다. 초기에는 기존 문제 조건과 작은 새 대조군으로
원인을 좁힌다. 지표 개선을 본 뒤에 지정 음악 87구간으로 넓히며 무제한 탐색을 하지 않는다.
실제 기기 결과와 디지털/합성 결과는 구분한다. P1++ 후보가 생기기 전에는 P1+ 이름의
고정 기록을 덮어쓰지 않는다.

## 첫 분해 실행 결과 (2026-10-26)

P1+를 그대로 사용해 기존 문제 조건과 그 구성 요소를 나눈 10조건을 실행했다.
원래 혼합의 상대 윤곽 오차 RMS 82.7775%는 타격 잡음을 빼도 82.7769%로 거의 같다.
따라서 이 조건의 큰 오차에는 별도 타격 잡음이 필수 원인이 아니다. 잡음 억제를 더하는
것부터 시작하기보다 짧은 저음 자체의 필터·분석·추적·진폭 경로를 단계별로 확인한다.
입력 변조까지 제거한 조건도 오차가 컸다. 아직 어느 내부 단계의 결함인지는 확인하지 않았다.

이것은 기존 개발 조건의 원인 조사이고 새 독립 검증이나 P1++ 개선율이 아니다.
