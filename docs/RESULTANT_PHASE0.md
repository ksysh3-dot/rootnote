## Resultant 0단계: 생성층 상한 측정

**상태:** 측정 완료 (개발용 고정 합성 픽스처, 확인군 없음, 청감 점수 아님). 엔진·앱·기본값 변경 없음.
**브랜치:** `research/resultant-r0-20261029` (`research/study3-20261029` 위). 스크립트 `tools/pvb-harness/research_r0_ceiling.py`.
**모델:** P1 (Legato 1.0, ID 6 플래그 0), P1+C1 (Legato 1.1, stage 8192), P1+ (Preciso 1.0, 플래그 6). 세 모델의 상한 차이는 단음·AM·두 음 (간격 3 Hz 쌍 제외)에서 0.3 dB 이내라 아래 값은 P1이다. 짧은 음 충족도 중앙값은 P1 −1.1, P1+C1 −0.8, P1+ −1.0 dB.

### 질문
차세대 배음 지시서의 목표(동일 에너지 또는 동일 피크에서 유효 배음 RMS ×1.25 / ×1.5 / ×2)가 지금 구조에서 얼마까지 가능한가.
dB 환산: ×1.25 = +1.9 dB, ×1.5 = +3.5 dB, ×2 = +6.0 dB.

### 방법
- 픽스처: 단음 10개 (35–130 Hz), AM 3개 (55 Hz 3·7 Hz, 41 Hz 5 Hz), 두 음 5개 (9.5 s, 1–9 s 창: 평균율 음정은 두 음의 배음이 0.2 Hz까지 붙음), 짧은 음 8개 (41·55·82·110 Hz × 150·400 ms, 4회씩).
- 정상 구간 (단음 1–4 s) 생성층을 선 최소제곱으로 분해: 유효 = 입력 음의 k ≥ 2 배음 (AM 측대역 포함, 생성층 자체의 기본 주파수에서 맞춤), 기본음 k = 1, 유령 (k + ½) f, 혼변조 m f1 + n f2 (|m| + |n| ≤ 6), 기타 = 잔차. 주기도 기준 상한 (유효 선 ±3 Hz) 도 함께.
- 파고율: 실제 (48 kHz true peak), 유효 선 + 맞춘 위상, 유효 선 + 최적 위상 (배음마다 위상 하나, 크기 고정 → 배음별 포락선 유지; Newman 시작, clip-and-project, 재시작). 반복 5배·재시작 4배로 다시 돌려도 0.05 dB 이내로 같다 (수렴).
- 동일 에너지 상한 = −10 log10(유효 비율). 동일 피크 상한 = 20 log10(CF 실제 / CF 최적) − 10 log10(유효 비율).
- 두 음의 최적 피크는 두 음 각각의 최적 피크의 합 (서로 무관한 주기는 언젠가 위상이 겹친다) → 두 음 상한은 보수적이다.
- 단계별: raw_grain, tonal_after_gain, percussion, pre_filter, post_filter 탭에 같은 분해. 짧은 음은 HPSS 구동 (original_h / 같은 지연의 band, f에서 복조), 충족도 (음 동안 유효 에너지 / 정상음 유효 전력 × 음의 에너지 길이), 피크 (음 피크 / 정상음 피크).

### 결과 (P1)

| 입력 | 유효 비율 | 동일 에너지 상한 | 동일 피크 상한 |
|---|---|---|---|
| 단음 35 / 41 / 46 / 55 Hz | 100 % | 0 dB | +2.5 / +2.8 / +2.0 / +2.2 dB |
| 단음 65 / 73 / 82 Hz | 100 % | 0 | +1.5 / +1.1 / +1.2 |
| 단음 98 / 110 / 130 Hz | 100 % | 0 | +0.8 / +0.4 / +0.3 |
| 단음 10개 중앙값 | 100 % | 0 | **+1.3** (×1.17) |
| AM 3개 | 99.5–100 % | 0 | +2.2 – +2.7 |
| 두 음, 간격 ≥ 17 Hz (55/82.5, 65.4/82.4, 49/73.4) | 99.6–100 % | 0 | 0 – +1.2 |
| 두 음 41.2/55 (간격 13.8 Hz) | 43 % (혼변조 52 %, 기타 6 %) | +3.7 | +9.6 |
| 두 음 55/58 (간격 3 Hz, 분석 해상도 미만) | 0.5 % (혼변조 99 %) | 정의 모호 (두 음을 한 음 + 맥놀이로 처리) | — |

- 동일 피크 상한은 단음에서 전부 위상 몫이다 (유효 비율 100 %).
- 생성층 유효 에너지의 97–100 %가 150–300 Hz에 있다 (출력 필터 대역). 1.45 kHz 이상 0 %, 타격 경로 몫 0 %.
- 무효 성분은 raw_grain (합성) 단계에서 이미 같은 비율로 있고, 포락선 이득·타격 경로·출력 필터는 더하지 않는다 (41.2/55: raw 45/50/6 % → post 43/52/5 %).
- 짧은 음: 충족도 −0.5 – −1.9 dB (150 ms ≈ −1.5, 400 ms ≈ −0.6), HPSS 구동 손실 −0.2 – −1.3 dB, 피크 초과 ≤ +0.8 dB.
- 배음 크기까지 바꿀 수 있다고 할 때의 이론 상한 (옥타브 대역 신호의 파고율 ≈ √2): 단음 +1.1 – +3.9 dB, 중앙값 +2.9 dB.

### 해석
1. **동일 에너지 목표는 단음과 떨어진 두 음에서 불가능하다.** 유효 비율이 이미 ≈ 100 %다.
2. **동일 피크에서 실현 가능한 지렛대는 배음 위상 정렬뿐이다.** 중앙값 +1.3 dB, 55 Hz 이하 +2.0 – +2.8 dB, 110 Hz 이상 < +0.5 dB. ×1.5 (+3.5 dB)는 배음 크기까지 바꾸는 이론 상한으로도 46 Hz 이하에서만 닿는다.
3. **큰 여지는 가까운 음정에만 있다.** 41.2/55 (4도, 13.8 Hz)는 유효 43 %. 128 ms 분석 창의 분해능 (Hann 주엽 반폭 ≈ 15.6 Hz) 안에서 두 음이 한 봉우리로 합쳐져 사이 주파수의 배음이 만들어진다. 실제 음악에서의 빈도는 아직 재지 않았다.
4. **위험:** 위상 이득이 가장 큰 낮은 음에서는 150–300 Hz의 배음 간격 (35–55 Hz)이 청각 필터 폭 (ERB ≈ 40–57 Hz)과 비슷해 배음이 잘 분해되지 않는다. 이때 파형의 주기적 피크가 가상 피치의 단서라서, 파고율을 낮추면 피치 명료도가 약해질 수 있다. 청감 확인이 관문이다.

### 목표 제안
- 지금 출력 대역에서 "동일 피크 ×1.5 = 2.0" 기준은 위상만으로 도달할 수 없다. 2.0을 노리려면 배음을 스피커 효율이 높은 대역으로 옮기는 방향이 필요하고, 폰 실측 없이는 판단할 수 없다.
- **R1 위상 정렬:** 기대 중앙값 +1.3 dB, 낮은 음 +2 – +2.8 dB, 에너지·배음 크기 불변. 관문은 피치 명료도 대리 지표와 청감.
- **R2 가까운 음정 분리:** 해당 경우 +3.7 dB (동일 에너지) 이상. 먼저 실제 음악에서 빈도를 로컬에서 잰다 (음원 커밋 금지).
- 짧은 음 충족도 (+1 – +2 dB 에너지)는 연구 3에서 이어 간다.
