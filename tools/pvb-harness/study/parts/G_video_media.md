# G. Non-English video reviewers and media labs: speaker FR shortlist

Checked: 2026-10-23. This is a shortlist of sources only. No curves or numbers were copied.

**Goal.** Find a reviewer outside NotebookCheck, Bandicoot Lab, DXOMARK and GSMArena that publishes
measured frequency-response curves of phone loudspeakers. To be usable, the reviewer must have
(1) measured the Galaxy S26 Ultra, or else the S25 Ultra or S24 Ultra, and (2) measured several other
Android phones with the same method. With both, "phone X minus S2xU" can be taken inside that
reviewer's data.

**Bottom line.** No candidate meets both conditions on evidence I could check. One lead,
微机分 WekiHome, is confirmed to publish phone-speaker FR images. Two Bilibili one-off videos are
weaker leads. Bilibili pages, Zhihu, Weibo and erji.net could not be read with the tools available
(details below), so every Chinese lead still needs a manual check in a browser.

## Notes per candidate

**1. 微机分 WekiHome.** This is the only Chinese source found with confirmed phone-speaker FR
images. 新浪众测 article 188380 (author 撩数码, 2025-02-06) reuses its chart with the caption
"频响曲线大家看下就好" ("just take a look at the FR curves") and gives no method. The erji.net
forum thread tid=2358075 ("【版主说】聊聊作为主力机的荣耀/OPPO/苹果外放音质 有测试和创新云试听")
seems to be the same comparison; it could not be fetched.

Next step, done by hand in a browser:
- Open WekiHome's Bilibili space and search it for 三星 / S25 Ultra / S26 Ultra / 外放 / 频响.
- Look for a Bilibili 专栏 (column) or 动态 (post) that carries the charts as images, which can be
  read more easily than video frames.
- Check whether the method is fixed: mic model, distance, volume, signal.

If WekiHome has an S2xU curve and a fixed rig, it is the most likely source to pass both conditions.

**2. 红米K90 Pro Max 扬声器频响测试.** This is a single-video test and does not include a Samsung. It
is useful only if the same uploader has a series that includes an S2xU. Check the uploader's other
videos.

**3 and 4. Six-flagship and four-flagship speaker shoot-outs.** No Samsung appears in the titles, and
these are probably recorded-playback comparisons rather than measured curves. Low priority.

## Blocked or unreadable (not worked around)

- **bilibili.com video pages:** fetch returns only the page shell, with no uploader, description,
  chapters or subtitles. api.bilibili.com is blocked by robots.
- **zhihu.com** (questions and 专栏 columns): blocked by robots.
- **weibo.com:** blocked by robots.
- **erji.net:** redirect loop between http and https.
- **YouTube RSS feed:** blocked by robots. The channel page gives metadata only.
- **pconline methodology page, fmkorea.com:** blocked by robots.
- **ithome 951664, forum.sbenny.com:** client error.

Because of these blocks, the Chinese video ecosystem was searched only through search-engine titles.
A manual browser pass over WekiHome's Bilibili space is the one step most likely to change this result.
