# P1++ 회복 처리 연구 v0.2 — 광대역 2의 실패 원인과 수정

2026-10-26. **광대역 2에서 기존 후보(mode 2)가 만든 뒤쪽 악화의 원인을 찾고 수정했다.**
현재 fit과 이력 기반 fit이 모두 기존 문턱을 통과할 때 보류된 음을 정상 세기로 복귀시키는
mode 4를 구현했다. 추가 지연은 0 ms다. P1+ 연구 기준과 Android 기본값은 유지한다.
이는 P1++ 연구 후보이며 앱 채택 결정은 별개다.

뒤쪽 회복은 좋아졌지만, **타격 직후 80 ms의 잔여와 일부 정상 짧은 음의 윤곽은 악화한다.**
전체 타격 잡음 해결이나 실곡 음질 향상을 입증한 결과로 해석하지 않는다.

## 광대역 2와 개선 조건의 특징 차이

입력 파형만의 분류로 예외를 만들 근거는 없었다. 같은 광대역 2가 −12/−6 dBFS에서는
mode 2로 약 57.72/47.52 dB 개선되고 −1 dBFS에서만 46.32 dB 악화했다.
파형의 정규화한 스펙트럼 특징은 같아도 강도에 따라 내부 상태가 달라졌다.

| 확인 항목 | 개선된 킥 조건 | 최강 광대역 2의 악화 |
|---|---|---|
| 관측 주파수·트랙 ID·생애 상태 | P1+와 mode 2가 같음 | P1+와 mode 2가 같음 |
| 입력 H/P 분리·타격음 경로 | 두 모드가 같음 | 두 모드가 같음 |
| 달라진 곳 | 새 트랙의 인정·생성 세기, 일부 조건은 뒤쪽 적용 이득 | 원래 지속음의 재인정 뒤 세기 복귀 |
| 뒤쪽 이득 | 조건에 따라 차이 있음 | 양쪽 모두 정확히 1; 뒤쪽 전역 이득 탓이 아님 |
| 원인 해석 | 현재 fit이 좋지 않은 새 음을 보류하는 효과 | 보류 후 인정된 정상음에 불필요한 느린 복귀가 남음 |

배경은 약 74.38 Hz 지속음이다. 타격 중 기존 트랙은 약 83.69 Hz까지 끌려갔고,
다시 잡힌 트랙 ID 12가 75 Hz 부근에서 74.38 Hz로 안정됐다. 이 재관측 주파수 경로는
P1+와 mode 2가 같았다. P1+는 인정된 새 트랙을 fade=1로 시작하지만 mode 2는 처음 보류한
트랙을 나중에 기존 트랙으로 인정하면서 0에서 서서히 복구했다. 음원 기준 분석 중심
1.378/1.421/1.458초에서 fade는 약 .901/.976/.993이었다. P1+는 모두 1이었다.
이 불필요한 진폭 변화가 뒤쪽 잔여 지표에 들어갔다. 새로운 잡음 주파수가 생겼다고 단정하지 않는다.

## 적용한 처리

mode 3은 최초로 인정받는 순간 기존 정상 새 음과 같이 fade=1로 복귀한다. 광대역 2를
고쳤지만 일부 타격 에너지가 커졌다. 이를 보존하고 mode 4도 비교했다.

mode 4는 처음 거부된 이력을 한 비트로 기억한다. 변조 모델이 유효하면 기존 방식대로
먼저 음을 인정할 수 있지만, **현재 stationary fit과 최종 effective fit이 모두 기존 −15 dB
문턱을 통과했을 때만** 한 번 정상 시작 세기로 복귀한다. 이후 기존 흐름을 따른다.
주파수·위상을 재시작하지 않고 기존 grain/겹침 합성을 유지한다. 새 분류 문턱이나
광대역 전용 분기를 만들지 않았다. −15 dB는 내부 모델 적합도 문턱이며 음량 기준이 아니다.

mode 4는 탐색용 새 조건에서 mode 3보다 타격 세기 변화를 작게 유지해 이번 회복 후보로 선택했다.
마지막 확인 조건을 읽기 전에 선택을 고정했으며, 그 결과를 본 뒤 DSP를 다시 조정하지 않았다.
mode 3의 정상 짧은 음 윤곽이 더 좋은 결과도 남겼다. 모든 지표에서 mode 4가 우위인 것은 아니다.

## 광대역 2와 기존 개선의 보존

최강 광대역 2의 뒤쪽 잔여 RMS는 출력 −18 dB 조건에서 다음과 같다.

| 처리 | 절대 잔여 RMS (dBFS) |
|---|---:|
| P1+ | -150.66 |
| 기존 mode 2 | -104.35 |
| 수정 mode 4 | -151.46 |

큰 상대 차이와 낮은 절대 수준을 함께 본다. 이 시험의 −104 dBFS 잔여만으로 사용자가
폰에서 들은 큰 잡음을 재현했다고 주장할 수 없다. −12/−6 dBFS에서 얻었던 큰 뒤쪽 감소는
mode 4에서도 유지됐다. 최강 킥 6조건의 감소는 각각
5.41, 10.08, 2.89, 16.41, 4.88, 12.46 dB였다.
이 6조건의 타격 에너지 변화는 -0.147~+0.001 dB다.

## 새 파형 확인과 남은 예외

표의 개선/악화는 P1+ 대비 **0.1 dB를 넘는 지표 변화**를 세었으며 청감 문턱이 아니다.
독립 파형 수와 세기 설정 수를 구분한다. 동일 파형의 세기 반복을 독립 표본으로 세지 않는다.

| 조건군 | 파형 / 세기 설정 | mode 2 뒤쪽 개선 / 악화 | mode 4 뒤쪽 개선 / 악화 | mode 4 직후 80 ms 개선 / 악화 |
|---|---:|---:|---:|---:|
| 기존 개발 조건 | 8 / 32 | 16 / 1 | 19 / 0 | 1 / 17 |
| 추가 탐색·선택 조건 | 12 / 36 | 9 / 6 | 18 / 0 | 4 / 11 |
| 고정 후 마지막 확인 | 8 / 24 | 9 / 4 | 13 / 0 | 2 / 10 |

기존 8파형(seed 2026102608)은 원인 조사에 사용한 개발 자료다. 추가 12파형(seed 2026102609)은
mode 3/4 비교와 선택에 사용했다. 마지막 8파형(seed 2026102610)은 선택 뒤 고정한 DSP의 확인이다.
세 조건군에서 mode 4의 뒤쪽 0.1 dB 초과 악화는 관측하지 못했다. 이는 이 유한 시험에서의 관측이며
음악 전반의 개선 확률이나 통계적 유의성은 아니다. 마지막 확인의 뒤쪽 개선 중앙값은 3.59 dB,
최대는 58.46 dB였다. 큰 수치는 매우 낮은 바닥까지 회복된 조건을 포함한다.

타격 **직후 80 ms**는 결과가 다르다. 탐색 조건의 최악 증가는 9.60 dB
(잔여 RMS 약 −78.72 → −69.12 dBFS), 마지막 확인의 최악 증가는 3.47 dB
(약 −71.27 → −67.80 dBFS)였다. 마지막 확인의 24설정 중 10설정에서 0.1 dB 넘게 증가했다.
앞쪽 약 150 ms의 성분은 대체로 바뀌지 않았다. 기존 개발 자료의 한 설정은 약 0.33 dB 증가했다.
마지막 확인의 타격 생성층 에너지는 −0.002~+2.252 dB 변했다.
뒤쪽 한 창만 좋아진 것을 전체 잡음 감소로 합산하지 않는다.

측정은 엔진이 보고한 지연으로만 음원 시간축을 맞추고, 같은 모드의 지속음 단독 출력을
뺀 뒤 알려진 입력 지속음의 1~8배음에 일정한 복소 계수를 맞춰 제외한다. 뒤쪽 창은
타격 끝+80~500 ms다. 고정 위상 차이까지 전부 잡음으로 세지 않기 위한 합성 진단이며,
정상 음악의 광대역 어택·잔향을 정답 없이 잡음으로 분류하지 않는다. 원래 에너지 지표도 보존한다.

## 정상 짧은 음과 변조

다음은 기존 짧은 음 6조건의 배음 윤곽 오차다. 음별 일정한 세기 배율 하나를 허용한 뒤
비교하며 dB가 낮을수록 작다. 절대 음량 오차까지 포함하는 전체 음질 점수는 아니다.

| 조건 | P1+ | mode 2 | mode 3 | mode 4 |
|---|---:|---:|---:|---:|
| fresh_note_0 | -22.600 | -20.880 | -22.902 | -20.880 |
| fresh_note_1 | -22.191 | -23.099 | -22.362 | -23.099 |
| fresh_note_2 | -21.338 | -20.664 | -21.182 | -20.664 |
| fresh_note_3 | -1.642 | -1.909 | -1.718 | -1.909 |
| fresh_note_4 | -26.416 | -26.406 | -27.033 | -25.570 |
| fresh_note_5 | -24.330 | -23.841 | -25.078 | -23.109 |

mode 4는 P1+ 대비 2조건 개선, 4조건 악화했다. 최대 악화는 약 1.72 dB
(상대 윤곽 RMS 약 7.41% → 9.04%)다. 45 Hz의 어려운 조건은 약 82.78% → 80.27%로 여전히 나쁘다.
정상 AM 깊이는 3/7/11 Hz에서 .708/.645/.548 → .693/.652/.552였다.
3/7 Hz 깊이 기준은 통과했고 11 Hz는 P1+와 후보 모두 기존 깊이 기준을 통과하지 못했다.
변조 시점·위상 기준은 세 조건 모두 통과했다.

## 지정 음악의 처리 변화

TestSound test 3와 Rayark Dream/Fighting Spirit/Mirage에서 입력만 보고 고른 각 2구간을 재처리했다.
3초 사전 구간을 넣은 부분 처리이며 곡 전체를 처음부터 처리한 상태와 같다고 보장하지 않는다.
표는 P1+ 대비 **생성층 에너지 변화**이며 제거한 잡음량이 아니다.

| 06 - Chamber Chu - Fighting Spirit.flac 55.547 s | +0.737 | +1.725 | +0.676 |

Mirage 8.943초의 타격 창 생성층이 19.13 dB 줄었고, Mirage 33.063초에서는 앞쪽 생성층이
4.64 dB 증가했다. 이 변화가 잘못된 배음 억제인지 정상 저음 손실인지는 현재 정답 자료로
판정할 수 없다. 타격 보존이 모두 통과했다고 보고하지 않는다. Mirage 첫 타격은
mode 2의 −34.90 dB 감소가 mode 4에서 −19.13 dB로 완화된 것이며, 둘째 타격도
mode 2의 −11.51 dB에서 mode 4의 −0.81 dB로 완화됐다. 복귀 수정의 일부 효과는
실곡 처리 차이에서도 나타나지만, 남은 감소를 정상음 보존이라고 단정할 수 없다.
짧은 샘플은 4개 모드에 구간별 공통 재생 이득을 적용했다. 개별 파일별 음량 맞춤은 하지 않았다.
청취자에게 반복 AB를 다시 검증 책임으로 넘기지 않았다.

## 구현 검증과 범위

엔진 회귀 71/71, P1+ 고정 회귀(측정값 차이 0), 44.1/48 kHz의 mode 0/1/2
출력·생성층·추적 기록 비트 일치, 이전 mode 3 광대역 2 생성층 일치를 확인했다.
mode 1~4의 블록 크기·관측 기록 독립성, 스트림 앞부분 인과성, 초기화와 타 프로필 불변 검사도 통과했다.
지연은 48 kHz에서 8420프레임(175.42 ms), 44.1 kHz에서 7737프레임(175.44 ms)으로
P1+와 같았다. 이는 전체 보고 지연이며 이번 회복 처리의 추가 지연은 0이다.
렌더 파일의 메타데이터는 P1++ 실험과 비교 기준 P1+를 구분했다.
직전 커밋 c2f9104의 GitHub 호스트 검사와 APK 빌드도 성공을 확인했다.

음악 스크립트의 별도 리미터 12설정은 mode 0의 대조군이다. mode 4의 전 출력 조건이나
삼성 보호 처리를 검증한 것으로 확대하지 않는다. 휴대폰 재생·녹음·전력·발열은 측정하지 않았다.

## 다음에 해결할 정확한 대상

광대역이라는 이름으로 예외를 두는 대신, 보류 후 정상 복귀의 상태 불일치를 고쳤다.
남은 우선 대상은 타격 끝~80 ms의 모델 불일치와 정상 짧은 음의 손실이다.
mode 2/3/4의 인정 시점, fade 복귀와 겹침 합성 단계의 에너지를 분리하고, 뒤쪽 감소와
직후 증가를 동시에 비교해야 한다. 그 비용을 해결하기 전 P1+를 자동 교체하지 않는다.
