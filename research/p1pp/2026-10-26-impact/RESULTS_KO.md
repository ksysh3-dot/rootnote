# P1++ 강한 타격 전후 잡음 연구 — 1차 결과

2026-10-26. P1+ 기준은 유지했다. 새 트랙의 첫 인정 조건을 강화하는 호스트 연구 옵션(mode 2)을 구현했다.
추가 지연은 0 ms다. 기본 mode 0은 P1+ 출력과 비트 단위로 같다. Android 기본 모드나 APK에는 연결하지 않았다.

## 확인한 것

사용자 증상은 강한 ‘쾅’ 전후에 잡음이 치솟았다가 안정되는 느낌이다. 동일한 타격 파형을
입력 피크 −36/−24/−12/−6/−1 dBFS로 높이고, 지속 저음 유무와 P1/phase-only/P1+를 비교했다.
입력 클리핑 없이도 강도에 따른 상태 변화가 있었다. 기존 킥+지속음 조건에서 생성층의
차이 신호가 자체 피크의 −40 dB 기준 아래로 30 ms 유지되는 시간은 P1+에서
−24/−12/−6 dBFS 순서로 약 12.5/47.5/82.5 ms였다. 이는 청감 잡음 회복 시간을 직접 측정한 값은 아니다.

## 수정한 곳과 두 후보

기존 P1은 onset/falling 구간에서 현재 stationary fit 대신 이력 기반 residual을 사용할 수 있다.
유효한 변조 모델은 별도로 인정된다. 일부 타격에서 현재 모델 오차가 큰 새 트랙이 인정되는 것을 관측했다.
그것만으로 잡음이라고 판정하지 않고 다음 두 반사실적 옵션을 비교했다.

1. mode 1: 변조 모델로 설명되지 않는 피크는 onset 여부와 관계없이 현재 fit도 요구.
2. mode 2: 새 트랙이 최초로 인정받을 때만 현재 fit을 요구. 이미 인정된 트랙은 기존 규칙 유지.

기존 −15 dB fit 문턱을 그대로 사용했고 새 상수를 조정하지 않았다. mode 1은 일부 조건에서
부작용이 더 컸다. mode 2를 더 조사할 후보로 남겼으며 P1+로 채택하지 않았다.
알고리즘은 그대로 두고 판단 한 지점을 바꾼 실험이며, 원래 타격음을 제거하는 처리는 아니다.

## 새 파형으로 확인한 효과와 실패

규칙을 정한 뒤 새 난수 seed 2026102608로 6개 킥형 타격과 2개 광대역 타격을 만들고
각각 4단계 강도에서 P1+와 mode 2를 비교했다. 독립 파형은 8개다. 32설정을 32개 독립 파형으로 세지 않았다.
같은 실험을 지표 보완으로 재실행한 것도 새 표본으로 세지 않았다.

최강 입력 −1 dBFS의 킥형 6조건에서는 뒤쪽 잔여 성분이
**3.75~16.41 dB 감소**, 중앙값
**7.82 dB 감소**했다. 이 6조건의 타격 구간 생성층 에너지 변화는
**-0.15~+0.32 dB**였다.
전역적으로 타격을 크게 줄인 것만으로 설명되는 개선은 아니다.

광대역 한 조건에서는 뒤쪽 잔여가 **46.32 dB 증가**했다. 이 설정의 절대 잔여 RMS는
출력 −18 dB 조건에서 약 **−150.7 → −104.3 dBFS**였다. 큰 상대 증가와 낮은 절대 수준을 함께 기록한다.
앞쪽 잔여 성분은 대체로 바꾸지 못했다. 따라서 이 후보로 사용자 증상을 모두 해결했다고 말할 수 없다.
전체 새 32설정에서는 0.1 dB를 넘는 감소가 16개, 증가가 1개였고 나머지는 그 범위 안이었다.
이는 기술적 차이를 요약하기 위한 구분이며 청감 우위 판정 문턱이 아니다.

## 측정 지표를 바로잡은 부분

지속음만 따로 처리한 출력과 차이를 내면, 정상 배음의 고정된 위상 차이도 잔여에 남는다.
이를 전부 잡음으로 세지 않기 위해, 알려진 입력 지속음의 1~8배음에 해당하는 일정한 복소 계수를
각 관측 창에서 맞추어 제외한 잔여도 계산했다. 주파수는 출력에서 고르지 않았다.
원래 차이 신호 에너지와 회복 지표도 보존했다. 이 정의는 새 조건의 결과를 읽기 전에 기록했다.
그럼에도 제한된 합성 신호 모델이며 정상 음악의 광대역 어택과 잔향을 정답 없이 잡음으로 분류하지 않는다.
타격 끝+80 ms부터 +500 ms까지를 뒤쪽 창으로 사용했다.

## 정상 신호와 실곡의 비용

기존 짧은 음 6조건에서 mode 2는 윤곽 오차가 2조건 개선, 3조건 악화했고 1조건은 약 0.002 dB 차이였다.
가장 큰 악화는 약 1.72 dB였다(상대 RMS 약 7.41% → 9.04%). 45 Hz 어려운 조건은 약 82.78% → 80.29%로,
여전히 충분히 재현하지 못한다. 이 결과를 숨기거나 모든 정상음 보존을 통과했다고 쓰지 않는다.
정상 AM 깊이는 3/7/11 Hz에서 P1+의 .708/.645/.548에서 약 .693/.652/.552로 변했다.

TestSound test 3, Rayark Dream/Fighting Spirit/Mirage의 각 2개 강한 구간을 입력만 보고 자동 선택했다.
P1+/mode 1/mode 2를 같은 3초 사전 구간으로 처리했다. 8구간에서 mode 2의 생성층 RMS 변화는
약 −0.71~+0.41 dB였다. 예를 들어 Fighting Spirit 한 구간은 뒤쪽 층 에너지가 7.55 dB 줄었고,
Mirage 한 구간은 앞쪽이 4.64 dB 늘었다. 이 차이를 실곡 잡음 감소로 해석하지 않는다.
각 구간의 P1+와 mode 2 WAV에 공통 재생 이득을 적용했다. 사용자 반복 AB를 검증 선행 조건으로 두지 않았다.

## 리미터와 구현 검사

별도 킥+지속음 시험에서 출력 −18/−3 dB, VB +6/+9 dB, 입력 −12/−6/−1 dBFS의 12설정을
5 ms 간격으로 확인했을 때 앱 엔진 리미터의 최대 이득 감소와 작동 비율은 모두 0이었다.
이번 디지털 조건에서 관찰한 변화를 앱 리미터 탓으로 돌릴 근거는 없다. 폰 제조사 보호 처리는 측정하지 않았다.

mode 0의 기존 P1+ 출력 일치, mode 1/2의 블록 크기·관측 기록 독립성, 실제 스트림 인과성,
초기화, 다른 프로필 불변 및 44.1/48 kHz 지연을 확인했다. 엔진 회귀 71/71과 P1+ 고정 회귀를 통과했다.
P1+ 회귀의 측정값 차이는 0이었다. 이전 P1+ 커밋의 GitHub host/APK 작업도 성공한 것을 확인했다.
이번 후보는 호스트 코드와 WAV로 제공하며 휴대폰 청감·전력·발열 개선의 증거는 아니다.
