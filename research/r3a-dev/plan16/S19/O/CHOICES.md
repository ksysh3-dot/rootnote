# S19-O CHOICES (fixed before any oracle result; written 2026-10-31)

Only data inspected before this file: S19 cache structure, one probe of f4/Apparition trace around 3 note-change tags (to learn how the trace is built).
What the probe showed (MEASURED, used for the choices below): in row f4 the oscillator increment of hop q equals f_osc of hop q-1 exactly (F_q = (theta_q - theta_{q-1})/(2 pi hop) = f_osc[q-1]); no phase innovation, no phase step. f_osc follows f_track slowly (a 66-cent f_track step becomes a ~8-hop slew of f_osc), so "row f4's bare step" is a fast slew of F_q, not a discontinuity. theta_hat is unwrapped.

## 1. Rows, data, reconstruction
Main row f4 (beta 0/0, psi .01, v1.6-a base), reference row b3p2, row 1 = b0p0 (only as the "vs row 1" denominator). Cache = `S19/cache/r_<row>_sNN.npz` (14-field trace + 5 ms box energy of the rendered 20-150 Hz layer). 7 user windows and 14 songs as S19 (windows: tcb in [t0,t1), box centre input time; songs whole). Nothing new is rendered, no audio is read; only cached numbers are used (synthetic glide/vibrato signals for (e) are generated here and rendered with the f4 row, as A5P/fosc_p.py).
Reconstruction = B1-2 / S19 `slot_energy` rule, per voice run (consecutive hops, same slot and voice id, state >= 1), k = 2,3 only: block q (q >= 1 in the run, 16 core samples at 3 kHz starting at core index hop[q]) has
 - phase: theta ramps LINEARLY inside the block from theta_hat[q-1] to theta_hat[q] (constant increment = frequency step per hop, F_q = f_osc[q-1]); the phase of harmonic k is k*theta + psi_k, psi_k interpolated LINEARLY between hop ends psi_k[q-1] -> psi_k[q];
 - amplitude a_k interpolated LINEARLY between hop ends a_k[q-1] -> a_k[q] (no interpolation of frequency: it is piecewise constant per block);
 - sum over all runs/slots/k into one 3 kHz signal y (the interference of voices is kept; per-slot energies of S19 are only used as the voice-selection weights, taken from the baseline);
 - bands: zero-phase 4th-order Butterworth 20-150 Hz (lo) and 150-600 Hz (mid) at 3 kHz (S19 SOS3 / A5P conventions), NO kOutSos (A5P: rendered layer is not passed through it). Block energy E[q] = sum of the 16 squared samples. Box n -> hop hn by S19 mapping (centre time, nearest hop); box recon energy = E[hn] (3 kHz, 16 samples) vs render box (48 kHz, 240 samples) compared as mean power per sample.
 Check: baseline recon must equal S19 `slot_energy` summed per slot in the selection weights (verification printed in the log), and baseline box classes must reproduce s19_attr.json windows shares.
Baselines per variant are always the UNMODIFIED reconstruction of the same row (variants never change classes; classes come from the baseline trace).

## 2. Classes (box level, from baseline, S19 attribution)
S19 `attribute` logic reproduced exactly: 5 ms boxes, voice selection = smallest voice set covering 50 % of per-slot recon energy at the box's nearest hop, events within +-10 ms (8 types, list order, exclusive) -> class "event" (any of the 8 types) or "noevent" (voices present, none matched); "novoice" (no recon energy) listed separately (expected ~0). Event boxes for (f) = boxes with a note_chg-tagged hop of a selected voice within +-20 ms (any other class overlap allowed).

## 3. Sustain segments
Per voice run: a start event = birth (first ON hop), REL>ON, or a note change. Note-change event: S19 `note_chg` tags (|f_track(h)/f_track(h-2)| > 50 cent) of one slot-run grouped with gap <= 2 hops; group [g0..g1]; the change occupies hops g0-2..g1; event hop e = g0-2, group end g1. Sustain segment: starts 6 hops (32 ms ~ 30 ms) after the start event (birth/REL>ON: after the event hop; note change: after g1, i.e. after the movement ended), ends at the hop before the next start event (e of the next note change) or before the first ON>REL hop or at the run end; only state == 2 (ON) hops; a segment needs >= 8 hops (43 ms) else it is not modified.
Modified trajectories inside segments only:
 - F trajectory: F_q (q = s0..s1) from theta increments; a (amplitude) trajectories: a_2[q], a_3[q] linear amplitudes (not dB; zeros are legal), q = s0..s1.
 - Smoothing x -> x': subtract the end-to-end straight line, zero-pad the zero-ended residual by 3*fs/fc (<= 700) samples both sides, 2nd-order Butterworth lowpass at fc applied forward-backward (sosfiltfilt, so |H|^2 is 4th-order, -6 dB at fc, zero-phase) at the hop rate fs = 187.5 Hz, crop, subtract the straight line through the output ends (ends joined exactly), add the original line back; clip amplitudes at 0.
 - After F smoothing the deviation d = F'-F gets its mean subtracted over the segment so the integrated phase equals the original at the segment end (phase rejoins the original: theta'_{s1} = theta_{s1}); psi_k unchanged. (Side effect: F ends differ from the original by -mean(d).)
 - (e) causal: the same recipe with `sosfilt` (causal, 2nd order Butterworth, zero initial state of the zero-ended residual) instead of the forward-backward pass; end-join correction identical.
Variants: (a) F only, (b) amplitude only, (c) both, fc in {4,8,16,32} Hz; (d) both at 1 Hz; (e) causal versions of a, b and c at the same four fc (the "winner" is picked by the rule afterwards); (f) crossfade below.

## 4. (f) note-change crossfade
At each note-change event (first tagged hop group as above; requires run position of e >= 2 and ON at e-1 and e) over T in {5,10,20,40} ms (= 15/30/60/120 core samples, sample-level raised cosine, block start of e as t=0): the reconstructed voice waveform (k = 2,3) from the start of block e is multiplied by g_new = 0.5(1 - cos(pi n/N)), n = 0..N-1, N = T*3 samples; an old partial is added = k=2,3 waves with frozen amplitude a_k[e-1] and frozen psi_k[e-1], phase continuing from theta[e-1] at the constant old frequency F_old = F_{e-1}, times g_old = 1 - g_new. New partial = the engine's own trajectory of row f4 (its F_q slews to the new note; no extra step is invented). Because the trace has no measured-phase/measured-frequency of the new oscillator, this (f) cannot test "new oscillator started at the measured frequency"; stated as a limit. Baseline "bare step" = the unmodified reconstruction. Measured on event boxes (+-20 ms of note-change tags) and also all/noevent boxes. Overlapping crossfades of one voice (events < N apart) are applied in sequence.

## 5. Reporting and decision rule (mechanical)
- Per variant: total 20-150 recon energy of (i) noevent boxes, (ii) event boxes, (iii) novoice, (iv) all boxes, pooled over the 7 windows, and the 14-song median of per-song sums (dB). Reported (1) vs the row's own baseline recon (dB), (2) vs row 1 baseline recon (b0p0), and shares of row-1 total energy for noevent / event (like 19.1 "abs").
- Gain of a variant = - (dB change of the noevent boxes vs the row baseline) (positive = better). Primary = 7 windows pooled (the user-window metric); songs median reported next to it; the rule uses the windows pooled number for f4, and I say if the songs median contradicts.
- Projected layer ratio = f4 measured pooled ratio (A5P primary_summary: -26.19 dB; b3p2 -26.01; b0p0 -22.84; P1 -29.71) + dB change of the 20-150 recon energy (all boxes, windows pooled, vs row baseline), 150-600 assumed unchanged; also the recon's own 150-600 change (k = 2,3 only content) and a second projection that includes it.
- Render vs recon (4): per row, per class, 10 log10[(sum box render/240) / (sum E_lo[hn]/16)], windows pooled and song median.
- Rule (19.2): (1) if (d) lowers noevent energy by <= 1 dB (gain <= 1 dB): outcome "inspect synthesis path". (2) a vs b: compare each one's gain at its best fc; difference >= 2 dB -> only the larger is component B, else both. (3) fc = highest fc (of {4,8,16,32}) whose gain is within 1 dB of the best gain of the chosen form (c for "both"). (4) T = the T with the lowest event-box energy; ties within 0.5 dB -> shorter T. (5) stop only if (c) at 4 Hz and every (f) T give gain <= 0.1 dB (and 0.1 dB also for event boxes in (f)). "Gain of (f)" = reduction of nc20 event-box energy vs bare.
- (e): on the synthetic glide (100->150.5 Hz in 1 s) and vibrato (30 cent 5.5 Hz; 60 cent 4 Hz), clean and 25 dB pink SNR, as A5P/fosc_p.py (truth at the block centre input time (hop-100... S19 convention (ih-398+8)/3000+T0), estimate = F_q of the dominant ON voice (largest (A c sigma)^2), octave-folded): median |error| and median signed error in cent for unsmoothed, zero-phase, causal at each fc, with the same sustain segmentation applied to the synthetic traces. Real songs: RMS and p95 of |F'-F| in cent and of |20log10(a'/a)| (dB, hops with a > 1e-7) over all sustain segments of f4, zero-phase vs causal, per fc.
- Any method change after seeing results: first attempt kept in `results_v1/` and called out in the report.

New / changed (applies to `results/`, the main outputs):
1. NEW ROW `r1r` (r1render): analysis state = row 1 (b0p0) unchanged: b0p0 amplitudes a_2,a_3, psi_2, psi_3, states, events/classes/segments of b0p0. Render frequency per block = f_track[q-1] (no pull; same one-hop convention as F_q = f_osc[q-1]; f_osc used if f_track <= 0), phase integrated continuously from the b0p0 theta_hat of the run's first hop. Variants (a)-(f) applied on top. Limits: classes and tags are the b0p0 ones (no re-tagging for the new render); a_k not re-derived from the new frequency; no fade voices. Projection for r1r uses the b0p0 measured ratio and the b0p0 recon baseline as reference.
2. Phase-continuous joins: new F-arm = smoothing of the PHASE residual: phase theta over segment hops s0-1..s1, straight line through the two end phases, residual (zero at both ends) zero-padded and smoothed with the same filter, ends re-fixed to zero, line added back; phase is continuous at both joins by construction (frequency may have a small step there). Old mean-fixed F smoothing dropped from the main tables (kept in results_v1). Extra split: noevent boxes with a selected voice's segment end hop (s0 or s1) within +-10 ms = "join", the rest "interior".
3. Projected ratio = measured ratio of the row + (recon counterfactual dB - recon baseline dB) (all 20-150 recon energy, windows pooled); a second version also subtracts the recon's own 150-600 change. Recon is BEFORE the output filter (no kOutSos), k = 2,3 of the traced voices only, no percussive/other layer, no fade voices.
4. Spectrum 20-600 Hz of the baseline recon in frames (Hann 512 samples = 171 ms, hop 128, 3 kHz) of the 7 windows whose central +-43 ms boxes are >= 90 % noevent (also 70 %); lines vs skirt: running-median (31 bins) prominence, share of 20-150 power in bins > 6 dB above the running median, top lines with distance to 187.5 Hz multiples. Rows f4, r1r.
5. Selection of fc and T: median over the 12 songs excluding Apparition (idx 9) and Reminiscence (idx 6); the 7 windows are the held-out check (both shown). Rule unchanged.
6. Future needed for zero-phase smoothing per fc: time after which the forward-backward impulse response stays below 5 % and 1 % of its peak. Realizable rows: symmetric FIR, 2D+1 taps, h = truncated zero-phase impulse response renormalized to unit DC gain, D in {1,2,3} hops of future (= D hops of added synthesis delay), arms b and c, same fc grid, same end-line/zero-pad/join recipe.
7. (f): per crossfade event, the voice's k=2,3 waveform original vs crossfaded, both 150-600 Hz band-passed (zero-phase), sliding 6-sample (2 ms) power inside the crossfade window; dip = min over sub-windows of 10log10(P_xf/P_orig) (eps = 1e-3*mean P_orig); median and p10 over events. Runs shorter than 40 samples skipped.
8. r1r: median |phase error| of the render phase against b0p0 theta_hat (fundamental, wrapped, per ON hop), plus p90 and first-30-hops value; the k=2 error is twice the fundamental one.
