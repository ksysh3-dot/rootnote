# S19-LIM CHOICES (fixed before any result was looked at)
Question: with the layer at the user's strength (+6 dB) does the output limiter pump with the layer's low band? Offline measurement only, numbers only.

Chain (app defaults read from PvbAbConditions.v11 / PvbSettings.kt / pvb_engine.cpp defaultParams, identical): hp LR4 100 Hz; low-mid bell 220 Hz +3 dB Q 1; treble bell 4.5 kHz -3 dB Q 0.6; output gain -5 dB (before the limiter); limiter ceiling -1 dBTP, release 60 ms, look-ahead as built in; dynamic low-mid / treble shelf / XTC / experimental options off; ramp 0; enabled 1; flat 0. Layer level = P_VB_LEVEL_DB (+6 main, 0 secondary; the app default VB_LEVEL_DEFAULT is +6). "Layer off" = same algorithm and latency, P_VB_LEVEL_DB = -120 (VB_LEVEL_OFF), same limiter.
Library: tools/pvb-harness/build_core19/libpvbcapi.so for all rows. Block = 256 samples, fs 48000 (songs resampled with resample_poly as in A5P/p_primary.read_song, 2 channels).
Rows: P1 (algo 6); v1.5 (algo 15, voicing 0, ampSource 0, other Resultant params default); v1.6-b (v1.5 + capRho 1.5, windowCreep 16, creepMode 2, betaMin .05, betaMax .1, psiSlew .03); v1.6-c (v1.6-b + layerHpHz 150, layerHpOrder 8, layerHpComp 1); layer off (one run per row's algorithm, so the latency is the row's own).
Data: 7 user windows (P.WINDOWS: Apparition 52.0, 88.5, 123.5, 201.0, 203.0; Reminiscence 96.0, 113.0; 2 s each), the song rendered from its start up to the window end + 2 s (causal engine: later audio cannot change the window, so the state is as warm as with the whole song). 12 held-out songs (sorted vanila index not in {6, 9}), excerpt = 30 s from 60.0 s (moved back so it ends >= 1 s before the song end; skipped if < 31 s), rendered from the song start to the excerpt end. Latency removed from every output/layer series (input timeline).

Two engine runs per (song, row, strength): L = the app chain (limiter active). U = "twin" with output gain -25 dB and ceiling 0 dBTP (the limiter never acts; the layer does not depend on output gain), scaled +25 dB afterwards = pre-limiter signal (full mix `pre`) and, from the diagnostic capture of U, the layer alone at output scale (`lay`). Sanity check (recorded in log): on blocks with GR meter = 0, |L - pre| must be < 1e-4 of the peak.

Measures (segment = one 2 s window, or the 30 s excerpt; every filter is applied to the whole rendered signal, then cut):
1. GR_meter = M_LIM_GR_DB read after every 256-sample block (largest reduction inside the block, dB >= 0; resolution 5.33 ms); block k belongs to input time (256 k + 128 - latency)/fs. GR_fine = per 48-sample (1 ms) stereo gain g = sum(L*pre)/sum(pre^2) of the twin runs, GR = -20 log10 g (0 where the pre-limiter energy of the ms < 1e-10). Shares of time with GR > 1 dB and GR > 3 dB (both series), mean GR, 99th percentile and max of GR_meter.
   Pumping = rms (dB) of GR_meter band-passed 2-12 Hz (butter 2nd order, sosfiltfilt on the whole GR series at fs 187.5 Hz) over the segment. Also the same for GR_fine decimated to 1 kHz (2-12 Hz).
2. Output band = mono mean (L+R)/2 of the limited output, butter 4 band 20-400 Hz sosfiltfilt. Peak |x| over the segment (dBFS), median of 200 ms-window peaks (dBFS); 2-12 Hz pulsing M = B1 mod_series (dB rms, 400-sample / 2 s windows hop 0.5 s at 200 Hz) of the 5 ms box RMS dB envelope (floor -90) of the band signal; the 2 s window gives one value, the excerpt the mean over its windows. Everything also as difference to "layer off" of the same row (same limiter) in the same segment: d_peak, d_M. Note: L signal is after the limiter (what the speaker gets).
3. Layer low band = `lay` mono mean, butter 4 band 20-150 Hz sosfiltfilt; level per 256-block (rms dB, floor -90) on the GR_meter grid. burst block = level >= trailing 200 ms (38 blocks) median + 6 dB and level > -60 dBFS.
   a. Pearson r(GR_meter, layer-lo level), lag 0 and the best |r| over lags -10..+10 blocks (positive lag = GR later than the layer);
   b. same r with dGR = GR_row - GR_off (layer's contribution), lag 0 and best;
   c. P(GR>1 dB | within 0..4 blocks after a burst block) vs P(GR>1 dB | other blocks) and the share of GR>1 dB blocks that lie 0..4 blocks after a burst;
   d. among GR>1 dB blocks of the row: median over blocks of (layer-lo block peak) / (pre-limiter block peak) in % (amplitude), and share with GR_off < 0.25 dB at the same block ("layer-caused" blocks = GR_row > 1 and GR_off < 0.25).
   Pooling: 7 windows pooled by concatenating blocks; Apparition 3:21 + 3:23 pooled "A-late"; the other 5 windows pooled "others"; held-out = median over songs of the per-song excerpt value.
4. Per window table of the main numbers (7 rows) for the +6 dB row set; A-late vs others.
