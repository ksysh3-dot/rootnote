## 1. Definitions (units, time axes, stem-aware)
* Metric "silent wrong_sa" = rendered energy of the sum of the components 3..7 (= 2 + V cause 1..5) of silence-class voices (cls = 2, sa-wrong samples), the five components rendered together (the V "rendered together" value 0.2121).  Right layer F = comp 0 + comp 1.  All energies over t > 0.5 s (`I_MIN`) and, as the main/B3 span, over t >= 4 s (render sample index 12000).  Both reported; the t >= 4 s value is the decision value (B3).
* Cause tags are those of V/K (`SongCtx._prep`, order 1-5, from the unmodified core) and are kept per voice per render sample; the gain changes `amp` only (never f), tags are not reclassified (16.10.1 M6 path: trace amp x gain -> `render_multi` semantics).
* Time axis of everything: layer/MIDI time = hop time `tc[h] + LAG` (LAG = -0.012 s).  P(h), gain and the stable scan live on the trace hop index h; a render sample at layer time tt maps to hop `h = rint((tt - LAG - tc[0]) / HOP)` (HOP = 16/3000 s = 5.3333 ms).
* Bass sounding (stem-aware) = union of the -15 dB stem-activity intervals of the MIDI segments (`act15`: [on, off] if active, else the MIDI [s, e]); bass songs only.  "Silence length before t" = time since the end of the latest sounding interval (0 inside an interval; if none before t: t itself, the clip start being an arbitrary cut, so the first seconds of a bass song count as silence of length t).  For no-bass songs the silence length is infinite and every sample is class "no-bass song".
* Silent energy in a bin = rendered energy of the component set with the silence samples of that bin (sample-level, by the layer time of the sample); the bins are rendered separately and shares = bin / sum of bins (cross terms ignored as in V/K).

## 2. Causal stable voice, context P(h), gate gain (B2 + m3; the replacement wording of review_1613 B2)
* Per hop h only trace rows with hop index <= h are read: slot j is ON iff state == 2 (state codes seen: 0 none, 1 CAND, 2 ON, 3 REL) and coast == 0 and ftr > 0; the window of voice id v is the list of its last N_s hops (N_s = ceil(D_s / 5.3333 ms) = 19 at 100 ms, 29 at 150 ms) that ended at h; any hop at which the voice is not (ON and non-coast), or is absent, resets its window; a voice-id change in a slot is a different window (windows are keyed by voice id, ids reused after an interruption start empty).  f = `ftr` (trace tracker f, field 5), cents = 1200 log2 ftr.
* Stable at h iff window full (N_s hops), max - min of cents <= 30, and amp = A c sigma (the slot's value at h) >= q95(h-1) - 30 dB.  q95(h-1): running 95th percentile of amp over all (voice, hop) rows with state == 2 and coast == 0 and hop < h, kept as a 1 dB-bin histogram (bin = floor(20 log10 amp); the percentile is the lower edge of the bin where the cumulative count reaches 0.95 n), updated AFTER each hop's decision.  Fewer than 400 such rows -> the amplitude condition is true.
* P(h) = 1 iff some voice is stable at some hop in (h - nH, h], nH = round(H / 5.3333 ms) (188 / 375 / 750 hops at H = 1 / 2 / 4 s); P = 0 at the start (t < H, no stable voice yet).  The decision at h reads hops <= h only.
* Gate = ONE global gain (the P=0 rule "new and existing voices x g_cap" and the "voice born at P=0 keeps g_cap until its own or another voice's stable event" coincide with this): linear-amplitude gain G(h): at a hop with P = 1 G moves up towards 1 by (1 - g_cap) * hop / 10 ms (full ramp 10 ms), at a hop with P = 0 it moves down towards g_cap by (1 - g_cap) * hop / 30 ms (full fade 30 ms); starts at the hop where P changes (no look-ahead); initial G = g_cap (P = 0 at the start).  Gain applied to the voice amp at the trace hop of each voice hop, linear interpolation between hops (the render samples at 3 kHz are the same interpolation as the core amp).  The knots of a voice are its own hops, so a voice born at hop h sees G(h).
* Leak log: for every hop the largest trace hop index read by the decision (window entries, histogram last updated at h-1, current row at h) is logged (`stable_scan` returns `maxread`); criterion maxread[h] <= h for all h, all songs, both D_s; reported in stage 0.

## 3. Stage 0 (dev tracks = the 10 V6 songs, 0-30 s, core v1.5; g_cap = -24 dB for 0c)
Decision span t >= 4 s (B3); unrestricted numbers beside it.  All stop flags are evaluated on the t >= 4 s numbers; if the unrestricted numbers would give a different flag it is reported.
* 0a: silent-wrong shares per silence-length bin: < 0.25, 0.25-1, 1-2, 2-4, > 4 s and "no-bass song", per song and pooled.  R_long = (1-2, 2-4, > 4 bins + no-bass songs) / total.  Reported: pooled (all 10), bass songs excluding T25 (T60, T40, T01, T05, T12, T20; T40 has 0 -> excluded from the ratio), T25 alone, each song.  Stop (16.13): pooled R_long < 40 %.  Stop (M5): R_long(bass songs excl T25) < 10 % AND R_long(T25) < 20 %.  M2 'not testable' flag: R_long < 10 % for all of T01, T05, T12, T20 (reported).
* 0b: oracle, per H in {1, 2, 4}: voices (all voices, the gain at hop resolution) x -24 dB at every hop where the stem-aware silence length >= H, or in a no-bass song everywhere (the oracle silence threshold equals H, B3).  R_max = 1 - E_oracle / E_core of the silent wrong_sa (t >= 4 s), pooled excluding T25, with T25, per song.  Stop: R_max (pooled excl T25) < 50 % for EVERY H (a single H below 50 % only drops that H; reading chosen now because H is a grid axis).  The H-wise numbers are all reported.
* 0c (B1): the real gate on the core trace, g_cap = -24 dB, for each (H, D_s) (six pairs).  Per song (and T24+T26 pooled): (i) fraction of hops with P = 0 (t >= 4 s; unrestricted beside), (ii) R_P = share of the silent wrong energy (core, no gain) whose render sample lies on a hop with P = 0 (separate renders of the P=0 and P=1 sample sets, share = in / (in + out)), (iii) stable-voice onset events per second (voice becomes stable) over the hops without sounding bass (t >= 4 s; and over all hops), also the P 0->1 and 1->0 transitions per minute (m4), (iv) fraction of hops with P = 1 among the stem-aware bass-sounding hops of bass songs (t >= 4 s; pooled over the 7 bass songs and per song).  The per-hop (A)/(B) rates of the 16.13 text are not computed (B1: report only; the registered replacement is the actual-gate quantities).
  Stop: for EVERY (H, D_s) R_P (T24 + T26 pooled by energy) < 50 %; or for EVERY (H, D_s) (iv) (pooled) < 98 %.  A (H, D_s) that fails either is also dropped from the grid later (m2 is the same number: P = 0 time while bass sounds <= 2 %).
* 0d: first-note cost, report only (M1 thresholds below are fixed now): first-note set of a setting = all stem-aware bass notes (MIDI starts s with 0.5 <= s <= dur - 0.1) whose onset hop has P = 0 under that (H, D_s, g_cap) (includes notes in [0, H)); cost = first 200 ms right-layer (comp 0+1) energy, gated vs core (render with the real gain, `note_energy(., s, 0.2)`); per song: 10 log10(sum E_gate / sum E_core) dB over the first-note set and the fraction of notes with > 6 dB loss (notes with core energy < 1e-3 of the song median note energy skipped); songs with < 5 first notes are excluded.  Both g_cap = -12 and -24 dB are reported.
* M1 thresholds for the grid (fixed now, no post-hoc redefinition): per song first-200-ms right-layer energy >= core - 5 dB; <= 35 % of the first notes drop by more than 6 dB; 0d only reports; a cell violating either is dropped.
* The real-gate silent reduction and F change at the six (H, D_s) are printed in stage 0 as INFORMATION (the renders are needed for 0d); no selection is made on them in stage 0.

## 4. Grid (registered before results; 12 settings)
H in {1, 2, 4} s x D_s in {100, 150} ms x g_cap in {-12, -24} dB.  Fixed: q 95 percentile, -30 dB amplitude criterion, 30 cent, 400-row warm-up, 10 ms ramp up, 30 ms fade down, nH from H.
Selection (16.13 + 16.8.1 M9 style, applied mechanically): among the settings passing EVERY development condition (main metric M2, F, first note M1, m2, M4 guards, new synthetic guards, leak, P-1->0-while-bass-sounds = 0), the one with the largest silent-wrong reduction (t >= 4 s, sum excluding T25); tie within 1 %p -> smaller right-layer loss.  None -> "no setting": stop, record the failing items.  Frozen in `frozen_setting.json` before any confirmation song is processed.
Main metric M2 (all must hold): sum excluding T25 reduced >= 45 %; T25 not worse; T24 and T26 each >= 50 %; T23 <= core + 0.0005; at least 2 of {T01, T05, T12, T20} reduced >= 25 % (songs with core t >= 4 s < 0.002 count only through "<= core + 0.0005" and are not counted as 'reduced'; if fewer than 2 of the four have core >= 0.002 the item is 'not testable' only via the R_long < 10 % clause; else it is judged on the available ones as stated); T40 and T60 <= core + 0.0005.
F: pooled right-layer (comp 0+1, t >= 4 s) >= core - 0.5 dB; no bass song worse than -1 dB (no-bass songs excluded: 0/0).  m2: P = 0 time fraction while bass sounds <= 2 % in bass songs.  m4: P transitions per minute reported.  m1: matching-energy for other-instrument MIDI before/after for the no-bass songs reported.
